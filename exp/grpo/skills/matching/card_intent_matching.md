# 卡片-意图匹配

## 核心原则

**推荐对平台有利的卡片，前提是商家执行后确实能获益。**

- 如果"增加预算"能帮商家获得更多有效流量 → 放 Top-3
- 如果商家当前不适合加钱 → 不放 Top-3，推其他有价值的操作
- 不要让商家感到被平台"割韭菜"
- 绝不推荐与商家意图反向的操作

## 匹配步骤

### 1. 计划存在性校验（最高优先级硬约束）

**每张卡片都必须先过这一关，不通过的直接排到最后。**

卡片名称中包含计划类型前缀（smax_aa_、smax_am_、smax_am_x_、sd_aa_、sd_am_、msa_），必须检查预分析中该类型计划是否存在：
- 预分析显示商家**没有**该类型计划 → 该卡片优先级极低，排到最后
- 预分析显示该类型计划**已关停** → 除"重激活"类卡片外，其余排到最后
- 只有 creation 类卡片不受此约束（因为是新建计划）

示例：预分析说"计划：SMAX AM×3 活跃，无 SMAX AA"
→ 所有 smax_aa_ 开头的操作卡片（提预算/改出价等）优先级极低
→ smax_aa_create 不受影响

### 2. 花钱合理性判断

对每张"花钱类"卡片（含 budget_increase / manual_topup / campaign_creation），判断：

| 判断维度 | 合理 | 不合理 |
|---------|------|--------|
| 资金状况 | 预分析显示"健康"或"充裕" | 预分析显示"紧张"或"枯竭" |
| 广告效果 | 有消耗、ROI 达标 | 零消耗、ROI 远低目标 |
| 商家意图 | 预分析显示"扩量" | 预分析显示"收缩" |
| 计划状态 | 有活跃计划 | 多数计划关停 |

- 3 个以上维度"合理" → 花钱卡可以进 Top-3
- 2 个以上维度"不合理" → 花钱卡排到 Top-3 之后

### 3. 意图对齐

| 预分析意图 | 高分卡片 | 低分卡片 |
|-----------|---------|---------|
| 扩量 | creation、budget_increase、rapid_boost | troi_increase、budget_decrease |
| 收缩 | troi_increase、budget_decrease | creation、budget_increase |
| 调优 | bid_adjustment、roas_tuning | creation、大幅预算变动 |
| 冷启动 | creation、基础设置 | 高级优化、限流 |
| 观望 | 效果诊断、创意优化 | 大幅加钱、激进调参 |

### 4. Top-1 二次校验（防误排）

**在确定排名第 1 的卡片之前，做最后一次检查：**

排在第 1 的卡片必须同时满足：
- 通过了计划存在性校验（步骤 1）
- 与商家意图方向一致（步骤 3）
- 如果是花钱类 → 通过了花钱合理性判断（步骤 2）
- 不是商家近期刚手动操作过的同类参数（防重复推荐）

如果不满足 → 降到第 2-3 位，把第 2 位的卡片提上来

### 5. 替代推荐

当高分卡片被过滤掉后，优先推荐：
- 现有计划优化（出价调整、创意优化）
- 跨类型尝试（只有 SD 的商家推 SMAX 创建）
- 效果诊断建议
- 运营节奏建议（等数据积累后再扩量）

### 6. 站点调整

根据预分析中的站点策略倾向微调松紧度：
- 站点建议"降低门槛" → 花钱合理性判断可以更宽松
- 站点建议"加强判断" → 花钱合理性判断要更严格
