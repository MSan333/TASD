# 广告计划现状分析

## 任务
从 campaign_data 中分析商家的广告投放结构和效果现状。

## 分析步骤

### 1. 计划类型分布
统计各类型计划的数量：
- SMAX AA：全站推广商品，全自动（高托管）
- SMAX AM：全站推广商品，手动出价（半托管）
- SMAX AM_X：全站推广店铺/多品模式（高托管）
- SD AA / SD AM：旧版推广
- MSA：大促爆单包

记录哪些类型存在、哪些不存在（影响卡片可用性）。

### 2. 活跃度判断
| 条件 | 判定 |
|------|------|
| 多数计划 Active + 有消耗 | 活跃 |
| 有计划但消耗低/为零 | 低活/冷启动 |
| 计划状态多为 OFF/Inactive | 收缩/停投 |
| 计划数 ≤ 2 | 基数低，属于冷启动 |
| 计划数 > 15 | 高基数，属于成熟期 |

### 3. 风险检查
- OOBU 风险：某类型计划的预算使用率 ≥ 85%（需精确到计划类型）
- 长期计划：end_date = 3020年的计划不需要推"延长投放时间"
- 效果指标：ROI/CPA 是否达标（如果数据中有的话）

### 4. 生命周期阶段
| 信号组合 | 阶段 |
|---------|------|
| 计划少(≤3) + 消耗低 | 冷启动：优先创建新计划 |
| 计划适中 + 消耗增长 | 成长期：优先优化出价/预算 |
| 计划多 + 消耗稳定 | 成熟期：精细化优化 |
| 计划OFF多 + 消耗下降 | 衰退/收缩：慎推扩量 |

## 输出格式
一句话：`计划：{类型分布概要}，阶段：{生命周期}，风险：{OOBU/无}`
例：`计划：SMAX AM×3 + SD AA×1 活跃，阶段：成长期，风险：SMAX AM OOBU`
