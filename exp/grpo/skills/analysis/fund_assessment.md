# 资金状况评估

## 任务
从 wallet_data 中评估商家的资金健康度，判断商家当前是否适合增加广告投入。

## 分析步骤

### 1. 核心指标计算
- balance/l7d_spend 比值（资耗比）：
  - > 5：资金非常充裕
  - 3~5：资金健康
  - 1~3：资金偏紧
  - < 1：资金紧张/枯竭
- OOBA 风险：balance / l7d_avg_spend < 3 即有风险

### 2. 资金阶段判定
| 条件 | 阶段 |
|------|------|
| balance 极低或为 0 | 枯竭：必须充值才能继续 |
| 资耗比 < 1 | 紧张：优先充值，不宜扩量 |
| 资耗比 1~3 | 偏紧：可维持但不宜大幅增投 |
| 资耗比 3~5 | 健康：可以适当扩量 |
| 资耗比 > 5 且 l7d_spend > 0 | 充裕：资金闲置，适合扩量 |
| balance 高但 l7d_spend = 0 | 冷启：有钱没花，需要激活 |

### 3. 花钱合理性判断
**核心原则：推荐对平台有利的操作，前提是商家执行后确实能获益。**

花钱类卡片（budget_increase / manual_topup / campaign_creation）是否合理：
- 合理：资金健康 + 有消耗基础 + 商家有扩量意图
- 不合理：资金紧张、刚充值但零消耗、ROI 远低于目标
- 不合理时不要推花钱卡到 Top-3，推优化类替代

## 输出格式
一句话：`资金：{阶段}（资耗比={数值}），花钱建议：{合理/不合理/视情况}，理由：{一句话}`
例：`资金：健康（资耗比=3.5），花钱建议：合理，理由：余额充足且有稳定消耗`
